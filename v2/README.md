# v2 · editorial edition

The second edition of Leonardo Carvalho's portfolio, built beside the terminal
edition at the repository root so the two can be compared. Static HTML, CSS and
vanilla JavaScript; no framework, no build step. Every page reads without
JavaScript. Search is the only feature that needs it.

## Preview

```sh
python3 tools/serve.py 8778
```

Then open `http://127.0.0.1:8778/v2/` for this edition and `http://127.0.0.1:8778/`
for the terminal edition.

## Files

| Path | Purpose |
| --- | --- |
| `assets/css/site.css` | The one stylesheet. Every token is a custom property on `:root`; `.stage` re-points the role tokens for dark bands |
| `assets/js/site.js` | Reveal and image settle, image tone on touch, clips, index filters and preview, résumé rail, search palette |
| `assets/fonts/` | Inter, Newsreader and JetBrains Mono, latin subsets, OFL |
| `assets/img/` | Derivatives only: WebP and AVIF, EXIF stripped. Sources stay where they were |
| `data/search.json` | Generated by `tools/build_search.py` from the HTML. Rerun after editing any page |

## Conventions

- Copy is first person, always "Leonardo", no en or em dashes, no superlatives.
- Facts come from the terminal edition's pages, `CONTENT-REVIEW.md`, the copy deck and the intake answers. Caveats travel with their facts.
- Images rest in grayscale and resolve on hover, focus or tap through one class, `.tone`; swap `--tone-rest` for a duotone later. Hockey images carry no class.
- Placeholders are `.ph` blocks with the ratio and subject in the label. Replace the block with a `.media` figure of the same ratio.
- Hidden-until-ready blocks (2026-27 stat tiles, schedule, PDF button) carry the `hidden` attribute and an HTML comment saying what fills them.
- Motion is 300 ms or less and off under `prefers-reduced-motion`.
- Keep `<meta name="robots" content="noindex">` on every page.

## Search index

```sh
python3 tools/build_search.py          # rewrites v2/data/search.json
python3 tools/build_search.py --check  # exit 1 if it is stale
```

Elements with a `data-search` attribute become entries: the value is the kind,
the first heading inside is the title, the first paragraph is the snippet.
