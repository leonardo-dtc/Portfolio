01

Problem

Three audiences read this site at three speeds. A hockey coach wants a recruiting profile that loads fast and prints on one page. An admissions reader wants to know what the work is and whether it holds up. A peer wants to see how it was made. So the Home page curates, the Résumé catalogues, and the project pages prove.

02

Two editions

The first edition is a terminal: an ASCII field on a canvas, a name rasterized from a bitmap font, a portrait and a goaltender’s mask baked into text, a working prompt in the corner and three small games. It is still at the root of this site, as v1, and the games live there.

This edition is paper. Light is canonical, one hairline of crimson runs under the chrome, photographs rest in grayscale and resolve to color when you reach for them, and the pages are meant to be quiet at first and more detailed the deeper you go.

03

Design system

Every color, type role and duration is a CSS custom property on the root, so a dark theme can be added by re-pointing them. The palette is paper, ink, a secondary gray, a hairline, and oxblood for the accent; the dark stage bands used for film and hero media swap in a lighter ink and a brighter red, because oxblood fails on black.

Inter carries the interface and the body text at 16 to 18 pixels on a measure of 60 to 70 characters. Bodoni Moda carries titles and pull lines. JetBrains Mono is reserved for index numbers, metadata and captions, and nothing on the site is set below 12 pixels.

04

Interaction

Motion is limited to 300 milliseconds, never runs before content is readable, and switches off under the reduced-motion preference. Titles clip-reveal once as they enter the viewport; images settle by one to two percent. The image treatment is a single class, so a crimson duotone can replace the grayscale later. Clips play muted on hover and on tap, and never with sound.

The search palette opens with ⌘K or a slash and searches projects, résumé entries and pages. The HTML is the source of truth: a small Python script scans the pages and writes the search index, and the site reads fully without JavaScript.

05

Implementation

Static files in a directory tree, one stylesheet, one small script, latin font subsets served from the same folder, images as WebP and AVIF with width and height set and lazy loading below the fold. Every page carries a print stylesheet; the Hockey page prints to one sheet. The site is marked noindex while it is a comparison build.

06

Current state

v2 is a comparison build beside v1. If it wins, the next step is a small generator so the shared chrome is written once.
