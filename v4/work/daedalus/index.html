Daedalus

A cooperative survival-horror game set in a changing labyrinth.

Status. Daedalus is at the design stage. There is no released gameplay to show yet, so this page has no images.

Premise

A first-person cooperative survival-horror game for two to six players, set inside the Labyrinth as Daedalus’s still-running machine. Players are meant to need each other: the game is built so that isolation is what it punishes.

Approach

We wrote a full design document before building: the systems, a bestiary, the items and a story with two endings. The rule for all of it is to show rather than tell. Every mechanic has a cause in the fiction, and the dread is meant to come from scale and wrongness rather than speed.

Interaction system

Cooperation is the core interaction: parts of the labyrinth need more than one pair of hands, and the labyrinth itself changes. Map sketches, creature concepts and a short loop of a two-player mechanism will be added here once they can be shown.

Implementation

Built on Roblox. I am the main builder; design and implementation are shared across the three of us as the project develops.

Current state

Working toward an alpha release. No release date has been announced.
