Five page transitions, buffer print kept as the baseline so you can weigh the new ones against something you already like. All five are built as an out() / in() pair, which is exactly how they will drop into the real controller.

my read

2 · Command line for both. It is the only one of the five that is not a decoration laid over the content — it makes the prompt in the corner do something. You click Research, the prompt types cd ./research, and the panel prints as the answer. Drill into a row and it types cat aducanumab.md. The navigation and the ornament become the same object, which is the thing the reference site never quite does.

It also solves the drill-down for free: a path that goes deeper is the most natural thing in the world for a prompt to show, and back is cd ...

  • 1 · Buffer print — still the safe pick. Calm, cheap, readable throughout. The command line is this plus a reason.
  • 2 · Command line — flashiest concept rather than flashiest surface. Adds ~350ms of prompt before the content starts; that is the real cost.
  • 3 · Hex decode — the flashiest surface, and distinct from the hero because it decodes structured 0-9A-F rather than the hero's noise glyphs. Watch it three times before committing; it is busy.
  • 4 · Signal tear — the most aggressive. Genuinely impressive once, and it fights the ASCII field behind it. Good as a rare accent, risky as the every-page move.
  • 5 · Depth push — the most physical and the least terminal. Cheap, handsome, and it would look at home on any portfolio, which is its problem here.
