What it is

This site is my portfolio, built by hand in HTML, CSS and JavaScript. Every page is its own HTML file, so it reads without scripts, prints, and keeps Back and Forward working. With scripts on, moving between pages keeps you in the same room, the way switching tabs does in a visionOS app, and a project opens as a sheet in front of the work behind it.

The room

The background is drawn in code after Apple’s Liquid Glass wallpapers: a navy sky, soft cobalt forms and a glass wave with one bright edge. It is a WebGL2 shader, so it moves slowly and leans away from the pointer, and it can go out of focus. The first page shows it blurred, and Enter pulls it into focus.

The name

The name on the first page is Sacramento’s letterforms, traced to their centre lines and chained into pen strokes in writing order, so it writes itself. Where the pen goes back over a line it retraces the same points, so no stroke doubles. The site ships the strokes as a small script and never loads the font. Pressing the name writes it again. Sacramento is by Astigmatic, under the SIL Open Font License 1.1.

The glass

The windows are glass drawn with the room, so they bend the light at their edges, frost what sits behind them and catch a highlight where the pointer is. The side windows are turned toward you, as in visionOS. Without WebGL, or with reduced transparency, the same windows use the browser’s own blur.

Current state

Built in September 2026 and not deployed yet. The type is each device’s own interface font, and the site makes no requests to other servers.
